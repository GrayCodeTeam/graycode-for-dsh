## 关键设计决策（已调研确认）

### DSH 事件挂点（自动存档）
- `tools/execute`（waterfall）：工具执行前/后 —— beforeTools/afterTools 存档（包装 `next()` 前后各建一次；失败 warn 降级不阻断工具）
- `agent/pre-step`：`payload.turn` 变化 = 新用户回合 —— beforeMessages 含 'user' 时存档
- `agent/turn-stopping`：模型回合关闭 —— afterMessages 含 'model' 时存档
- 差异文档化：DSH 无"工具批次"事件 → 逐工具存档（不做批内去重）；原插件 tool_batch 优化不移植

### checkpoints 新 Config
```ts
enabled: boolean            // 默认 true，总开关（false → 自动存档停 + 工具不注册）
autoCheckpoint: boolean     // 默认 true，自动存档开关
modelToolsEnabled: boolean  // 默认 true，7 个模型工具开关
beforeTools: string[]       // 默认 DSH 版 24 工具（原插件列表映射 DSH 工具名）
afterTools: string[]        // 同上
messageCheckpoint: {
  beforeMessages: ('user'|'model')[]   // 默认 ['user']
  afterMessages: ('user'|'model')[]    // 默认 []
  modelOuterLayerOnly: boolean          // 默认 true（仅根 agent）
  mergeUnchangedCheckpoints: boolean    // 默认 true（无变更不重复建）
}
```
- `origin: 'auto' | 'manual'` 字段：CheckpointSummary/records 持久化（旧数据缺省 'manual'），list 返回，client 显示徽标
- mergeUnchanged 实现：优先 service 变更预检；不可行则创建后 `backupBytes===0 && type==='incremental'` 判定回滚，最次文档化差异

### memory 新端点
- `memory/scopes` → `{ items: [{ scope: 'global'|'workspace', id, name, path, cwd? }] }`（global + 扫描 memory-workspaces/*/scope.json）
- `memory/forgetBatch` → 入参 `{ ids: number[], expectedRevision, confirm }`，confirm 门闸同 forget；返回 `{ removed, notFound }`

### 契约测试
- contract.test.ts 补 `memory/scopes`、`memory/forgetBatch`（仅 SA1 碰该文件）；src/remote/README.md 仅 SA1 更新 memory 段
